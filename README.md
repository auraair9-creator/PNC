# PNC — Projet No Cancer V2

V2 premium du site : identité PNC, design responsive, animations au survol, parcours de don, campagnes, témoignages, FAQ, contact, sélecteur FR/EN et dashboard admin de démonstration.

## Lancer
Ouvrir `index.html`.

## Paiements
Les paiements réels ne sont PAS activés. Le site stocke uniquement des dons de démonstration dans le navigateur.

Pour la production, connecter :
- PayPal
- Carte bancaire via un prestataire de paiement
- Orange Money
- MTN Mobile Money

Ajouter un backend + base de données + authentification + webhooks sécurisés + e-mails de reçu.
